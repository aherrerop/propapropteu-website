Product builder

This is a helper tool, not a live upload. GitHub Pages is a static host, so products can't be written to the server from the browser. Fill in the form, click Generate JSON, copy the block, and paste it into the "products" array in data/products.json, then commit. Put your images in assets/img/products/ first.
